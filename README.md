# IsoArch · Фронтенд (ЛР5)

**Лабораторная работа №5 · Вариант 18 · «Изотопные сигнатуры».** Базовое SPA на React для гостя:
просмотр исследований костных останков (δ¹³C, δ¹⁵N, описание рациона, фото, видео, лайки).

React 19 · TypeScript · Vite · React Router · React-Bootstrap. Без Redux и без React Context.
Данные карточек берутся только из коллекции mock-объектов, бэкенд не нужен.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка типов и production-сборка в dist/
npm run lint     # oxlint
```

Интерфейс сверстан под вертикальный экран телефона: в браузере на компьютере приложение
отображается колонкой шириной 390px по центру.

## Страницы

### Плитка — `/`

Каталог изотопных сигнатур в две колонки. Открывается при входе в приложение.

| Элемент | Описание |
|---|---|
| Верхняя панель | Логотип IsoArch |
| Заголовок | «Изотопные сигнатуры» |
| Поле «до … ‰» | Числовое поле, верхняя граница δ¹³C, шаг 0.1, от −25 до −10 |
| Слайдер | То же значение, шаг 0.5; слайдер и поле синхронизированы |
| Кнопка «Применить» | Показывает сигнатуры с δ¹³C ≤ выбранного значения (также Enter в поле) |
| Кнопка «Сбросить» | Видна только при активном фильтре; возвращает весь список и значение −10 |
| Карточка сигнатуры | Фото, название, бейджи δ¹³C и δ¹⁵N, число лайков. Клик (или Enter) открывает эту сигнатуру в ленте |
| «Ничего не найдено по заданному фильтру» | Показывается, если фильтр ничего не нашёл, с кнопкой «Сбросить фильтр» |

### Лента — `/feed` и `/feed/:id`

Одна сигнатура на весь экран в стиле Reels: фоновое видео, поверх — информация.
`/feed` открывает первую сигнатуру текущего списка, `/feed/:id` — сигнатуру с этим `id`.

| Элемент | Описание |
|---|---|
| Видео | Автовоспроизведение без звука, по кругу; постер — фото сигнатуры |
| Заголовок и описание | Описание обрезано до двух строк |
| Кнопка «Ещё» / «Свернуть» | Раскрывает и сворачивает описание |
| Чипы δ¹³C и δ¹⁵N | Значения изотопов, например `-19.5 ‰` |
| Сердечко с числом | Количество лайков (только просмотр, гость не может лайкать) |
| Кнопка со стрелкой вниз («Следующая сигнатура») | Переход к следующей карточке в том порядке, в каком они показаны в плитке (с учётом фильтра). После последней — снова первая |

### Нижняя панель навигации (на всех страницах)

Четыре пункта: **Лента**, **Добавление**, **Плитка**, **Вход**. Гостю в ЛР5 доступны только
«Лента» и «Плитка», активный пункт подсвечивается красным. «Добавление» и «Вход» показаны
приглушёнными и не нажимаются. Неизвестные адреса перенаправляются на плитку.

## Данные и медиа

- Mock-коллекция: `src/entities/isotopic-signature/model/mock.ts`. Поля совпадают с ответом
  веб-сервиса ЛР4 (`id`, `title`, `description`, `delta_n15`, `delta_c13`, `image_url`,
  `video_url`, `status`, `created_at`, `formed_at`, `likes_count`, `is_liked`, `is_creator`).
- Фильтрация: `getIsotopicSignatures(c13Max)` в `src/entities/isotopic-signature/api/`. Повторяет
  `GET /services?c13_max=…`, поэтому позже тело функции можно заменить на `fetch`.
- Если `image_url` / `video_url` пустые или файл не загрузился, подставляются
  `public/default_signature.png` и `public/default_signature.mp4`.

## Структура (Feature-Sliced Design)

В `src/` семь слоёв, импорты идут только сверху вниз:

| Слой | Содержимое |
|---|---|
| `app/` | Роутер (`App.tsx`), общий layout с `Outlet context`, глобальные стили и переопределение Bootstrap |
| `processes/` | Пусто: межстраничных сценариев в ЛР5 нет |
| `pages/` | `tiles` — плитка, `feed` — лента |
| `widgets/` | `tab-bar`, `top-nav`, `signature-grid`, `signature-slide` |
| `features/` | `c13-filter`, `expand-description`, `next-signature` |
| `entities/` | `isotopic-signature`: тип, mock, получение данных, форматирование, карточка |
| `shared/` | Маршруты и подписи, пути к медиа по умолчанию, хук подстановки медиа, иконки |

Список сигнатур хранится в состоянии страницы «Плитка» и передаётся в карточки через props.
Он же записывается в layout (`AppLayout`), откуда лента получает его через `useOutletContext`,
поэтому кнопка «Следующий» листает сигнатуры в порядке плитки.
