Лабораторная 6
Цель работы: Завершение интерфейса пользователя в React
Задание: Внедрить менеджер состояний для хранения значений фильтров, добавить авторизацию и возможность создания услуг через Redux Toolkit redux-thunk, кодогенерация взаимодействия с API через Axios
Содержимое карточек получать из вашего веб-сервиса. Ограничение с CORS решить через проксирование React (для S3 тоже добавить второй маршрут). В методах ajax предусмотреть получение данных из коллекции с mock-объектами при отсутствии доступа к вашему бэкенду (только как гость). Фильтры (по дате, названию или цене в зависимости от вашей темы как в 1 и 3 лабораторных) также добавлять в запрос к бэкенду. Добавить страницу Добавления услуги, кнопки удаления и лайков на соответствующих страницах.

Добавить страницу для авторизации. Добавление в Redux Toolkit состояния интерфейса после авторизации. В приложении должно быть реализовано переключение между интерфейсом гостя и интерфейсом пользователя по кнопке Вход/Выход. После авторизации в меню должно отображаться Выход. При выходе должен сбрасываться фильтр пользователя. Добавление менеджера состояний Redux Toolkit для хранения фильтра услуг. Рекомендуется использовать расширение для браузера redux-devtools.

Для обращений к методам веб-сервиса доменов услуг использовать axios, кодогенерацию и redux-thunk middleware. При выполнении запросов отображать на странице анимацию, блокирующую кнопки пользователя. Для запросов авторизации/деавторизации только axios, вручную передавать состояние в Redux без кодогенерации и thunk.

Дополнительная информация:
• Аутентификацию в этой ЛР мы делаем как в лекции 10 (не используем thunk). Для услуг мы thunk используем (как в лекции 11). Исключение: поле фильтрации услуг делаем как в лекции 10.
• В нашем курсе браузер отправляет запросы через прокси (это порт 3000 и https). https://localhost:3000 - baseURL.
• В этой ЛР мы сгенерируем код семи методов (см. подробнее лекцию 11, слайд 12).
• На каком-то примере из лекции сгенерирован метод login, но в этой ЛР мы пишем вручную.
• Мы специально создаём недостаток в этой ЛР, состояние 0/1 мы храним в Redux, а значит в оперативной памяти.
• По F5 наш интерфейс сбросится в гостя. Нам запрещено хранить признак 0/1 в local storage
